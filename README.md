# CAY_22
CAY_22 是一个基于 Python 的航空发动机控制参数计算与绘图工具。   
用于萨马拉国家研究大学24.03.05《ДВИГАТЕЛИ ЛЕТАТЕЛЬНЫХ АППАРАТОВ》   
第八学期《Автоматика и регулирование》课程项目的全部计算   
请先学习理解课程项目的内容再自行计算！CAY_22 仅提供验证作用！   

# 环境要求
运行本程序要求电脑已安装 Microsoft Office 2010 或更高版本   
请参照最新发布版的流程进行安装

# 基本功能
- Excel模板输入
- 自动参数计算
- 自动生成结果Excel
- 自动绘制特性图
- 自动生成日志

# 系统要求
建议：Windows 10 / 11

# 安装方式
1. 下载最新版的 exe 程序
2. 参照流程安装程序
3. 运行 exe 程序

# 使用流程
1. 下载最新版本的exe程序和excel文件
2. 将程序和文件放在同一个文件夹中，请勿修改excel文件名！
3. 打开excel文件修改原始数据
4. 保存并关闭excel文件
5. 双击运行exe程序
6. 程序自动运行生成带时间戳的文件

# 输出文件
- 所有计算结果均保存在 work.xlsx 表格中
- 在 plots_时间戳 文件夹内查看 图4~图17，这些图显示了相关参数的变化，具体含义请参考相关课程文件示例
- 运行日志 output_时间戳.txt 这个日志包含了所有运行过程以及曲线拟合函数结果
